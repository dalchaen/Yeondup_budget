# 연둡 가계부

아이폰 홈 화면에 추가해 앱처럼 쓰는 개인용 웹 가계부입니다.

- 주소: https://dalchaen.github.io/yeondup-budget/
- 모든 내역은 서버가 아니라 **이 기기의 브라우저(localStorage)** 에만 저장됩니다. 방문자에게 데이터가 전송되지 않습니다.
- 파일: `index.html` (외부 CDN·폰트 요청 없는 단일 파일)

### 아이폰에서 홈 화면에 추가
Safari로 위 주소를 연 뒤 **공유 버튼 → 홈 화면에 추가**.
- 아이콘: `apple-touch-icon.png` (180), `icon-512.png` (512)
